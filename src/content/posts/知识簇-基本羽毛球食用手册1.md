## 1 对羽毛球的个人理解

作为世界上 `初速度最快` 的炫酷运动，最能概括羽毛球特点的关键词我想应该是“帅”与“优雅”。

### 关于“帅”

羽毛球的动作绝对符合人体工学与美学，这是它的所有动作流畅而自然的最基本前提。

我们可以粗糙地将羽毛球技术动作拆解为手部与脚步两部分，羽毛球中几乎所有“正确”的动作都是相当舒展且美观的。

良好的触球应当是这样：从脚尖或者说小腿开始传递，通过腰部承接动作加强，最终凝聚到手腕甚至是手指上，从而羽毛球进行微操。

从这一系列的过程描述就可以看出，即便技术动作分为手部和脚步，但他们仍旧是相辅相成，协调且自然的。

所以一般而言，“好看”的动作就是正确的动作，而当你的动作“不好看”时，就应该思考自己的发力方式是否正确了。

### 关于“优雅”

“优雅运动”主要表现两个方面，一个是设备，一个是特性。

羽毛球是一项{% emp 室内运动 %}，因为球相当容易受到风的影响，且室外场地的灰尘与硬质颗粒对羽毛球场地与球鞋的塑胶与橡胶有极大的伤害性，长久之下必然会因打滑、球路乱飘等意外而受伤，算是一个相当“养尊处优”的运动，是不是有点贵族的意思呢？

其次羽毛球的各种装备耗材将会是你的一大开销。需要花钱的地方不仅有羽毛球本身，还有羽毛球鞋、球拍、拍线、手胶、场地费、球包、药品、护具以及各种小配件等等......

不过不用担心，我会在下面的章节中对成本做一个简单的预估，“青春版”羽球和“Pro Max版”羽球，你一定负担得起。{% del 大概 %}

如果说设备体现了贵族的地位与财富，那么在特性方面，羽毛球则是具有贵族精神或者说是气质。

和大多数对抗球类运动不同，羽毛球的比赛并不会产生直接的身体接触，也会要求观众的助威与加油处于一个比较安静的状态，只有在比赛的间隙才能听见呼喊，这是其他运动所不具备的“优雅”。

羽毛球并不是一项过渡依赖蛮力与身体素质的运动，你会发现球路的选择更多是一种策略与球商的体现，我们需要开动头脑来思考对面的战术与假动作，从而获得场面上的主动再到拿分，这是融合了力量的“智慧”。

而羽毛球的双打又与单打不同，双打将更加考验在场选手的轮转和协调，进攻与防守思路的同步，甚至在告诉的对抗中合作来一步步让对方调入自己所设置的陷阱，这是一份独特的“和谐”。

最后我们要明白，羽毛球是一个相当消耗体能的运动。在一球一球的相持当中，我们要保持自己的稳定与跟随，用高专注度的耐心和冷静的头脑控制住羽毛球飞行的轨迹，比拼自己和对方到底谁先出现失误，这就又是羽毛球“坚韧”的特性了。

综上所述，羽毛球是一个即具备物理贵族和魔法贵族属性的“上流运动”。但也许会令你惊讶的是，它又是一个常常出现在无风的街头巷尾，被光着脚的孩子拿着木拍鱼线捞起在网上来回穿梭的“平民娱乐”——毕竟很多东南亚发展中国家的羽毛球水平已超乎很多欧美国家很多年了。

::: info
中国、日本、马来西亚、丹麦、韩国、印度、泰国是目前较为公认的羽毛球强国。
:::

::: important 本节Point
- 良好的羽毛球动作流畅舒展且美观
- 羽毛球是室内运动，尽量不要在室外场地进行
- 羽毛球是一项综合性运动，与各种身体能力都有要求
:::

## 2 基础知识的Q&A

我们首先从几个问答入手吧。

### Q1 羽毛球会不会让某些部位变粗？

{% noteblock idea gray %}
Answer: 羽毛球不会让你“长肌肉”，但在{% emp 高强度 %}训练下需要注意左右臂训练量的平衡，普通球友则完全不用担心。
{% endnoteblock %}

也许有一些女生更为在意羽毛球运动到底会不会让自己变得更加漂亮或者长出小腿肌肉什么的，结论是不会。

首先，我们要明确一点，那就是女生并很难分泌一种和“雄性激素”的分泌正相关的叫做“睾酮素”的身体激素，而这种激素是生长肌肉所必须的。

因此身体自重训练，无药辅助训练，以及无药辅助的身体自重训练均不会让女生长出肌肉，也不会出现过度训练让小腿变粗这种无稽之谈。

当然，羽毛球是一项全身性的运动，作为减脂瘦身什么的那是相当绰绰有余。一场羽毛球比赛绝对会比跑个1000m什么的消耗掉更多的热量。

{% noteblock message cyan :: 什么是身体自重训练？ %}
身体自重训练 -- 就是没有使用重量器材的锻炼方式，例如无负重的跑步、深蹲、俯卧撑等。而哑铃、沙袋等相关的运动被称为负重训练。
{% endnoteblock %}

那么对于男生而言呢？很遗憾，虽然男生会分泌这种生长肌肉的激素，但是单单依靠羽毛球这一种运动方式是无法让你变成肌肉型男的——参考一下顶级羽毛球赛事的比赛录像就知道了。

但显然，羽毛球可以在目前肌肉量的状态下让你保持一个良好的体魄与形体，锻炼到身体中几乎任何一部分的肌肉，也许能帮助你显出腹肌也说不定。

对了，如果是要做系统的{% emp 大量训练 %}的话，要注意一下两只手臂的训练平衡。虽然这种情况在业余球友中{% emp 并不常见 %}，我们也需要注意一下不要出现只锻炼了惯用手导致两个胳膊并不一样粗细的滑稽事情。

### Q2 羽毛球对于学生有什么好处？

{% noteblock idea gray %}
Answer: 干净且效率的运动方式，有益于颈椎与脊椎，同时也是很好的发泄途径。
{% endnoteblock %}

首先它干净又卫生......相比较于室外运动这是显而易见的。

因为打球需要经常抬头，是锻炼颈椎的良好方式，在学习工作久坐之余能做一个良好的保养。

打球是一个的发泄途径，在大力击球轰击线床的同时可以发泄掉相当多的情绪和压力。

羽毛球也是一个非常迅速的锻炼方式，你可以在很短的时间内消耗掉一周所需要的锻炼量，作为日常的运动或者消耗方式是非常效率的。

当然，我们也可以依靠指定不同规则来让羽毛球有不同的锻炼效果，比如双打中加强与同伴的合作交流，减少的跑动范围和更少的击球频率也能让运动并不那么激烈；在半个场地上打球来减少跑动或者纯粹拉拉高远球来发泄情绪什么的，我只能说，你想要的形状，它都有。

### Q3 我需要购买一些什么东西呢？

{% noteblock idea gray %}
Answer: 球拍+球鞋+羽毛球
{% endnoteblock %}

关于装备的成本预估在下一个章节就会提到，不用那么紧张啦。

其实说得简单一些，我们需要购买的其实只有球拍、球鞋和球3样而已。

与常识稍相违背的是，球鞋在绝大多数有一定水平的羽毛球爱好者中是最重要的装备（没有之一），羽毛球鞋的设计使得它在防滑的同时能对脚踝做出一个强有力的支撑，其减震也是十分重要的保护，这些都使得球鞋在一定程度上甚至显得比球拍更重要——如果因跑不到位导致没有良好的姿态的话，无论如何也是没有办法好好挥拍的。

但一定要在球鞋上花费很多吗？在我看来，对于初学者不是这样的。不管怎么说，打球的大多数感始终会凝聚到击中球的那一瞬间，一个良好的触球体验对于培养兴趣或者正确发力都是相当有利的正反馈。因此，100~200RMB的训练球鞋已经足够满足初学者的使用需求了，留着的钱加到羽毛球拍或者其他配件甚至买个辣条，初学者没有必要听很多高手所谓的“球鞋比球拍花更多的钱”。

当然，一定要买羽毛球鞋。

而说到球拍，好的球拍能提升你的击球体验可不能提升你的水平，所以没有必要攀高价的拍子，一只300~400RMB的球拍就足够使用啦。

{% noteblock message %}
一个加钱买球拍而不是球鞋的重要理由：好球拍折价出二手是相当容易的，而基本上没有人会想穿别人穿过的鞋。
{% endnoteblock %}

至于球......{% del 我们蹭同学的球不就好了吗 %}

{% noteblock message %}
自带羽毛球是打羽毛球的重要礼仪，总是白嫖是一件很不礼貌的行为。尤其是请求和别人打球的时候，自己带上两个球总不会错。
{% endnoteblock %}

### Q4 打羽毛球需要什么样的天赋？

{% noteblock idea gray %}
Answer: {% span yellow :: 协调性 %}、反应能力、感知力、计算能力、爆发力、耐力与稳定性、观察能力。
{% endnoteblock %}

诚如上文所说，羽毛球是一个全身性的综合运动，因此其对身体各个方面都有所要求。

不过总得来说，身体协调性是绝对重要的一环，因为即便在最基础的挥拍过程中，我们就需要依次或同时调动小腿、腰腹、背部、肩部、手臂、手腕、手指这些部位的肌肉。就像好些个精密的齿轮，虽说即便某些地方并未完全贴合也不影响实际成果，但其效率和作用就往往出现瑕疵。

更不用说再复杂一点的技术动作了。

当然，实践与认识是对立统一的，认识能指导实践，而实践也是认识的来源。这也就是说，在学习打羽毛球的过程中，你的协调能力也将会有所提升，而其他身体能力也是如此。

### Q5 身高不高，可以打羽毛球吗？

{% noteblock idea gray %}
Answer: 羽毛球水平与天赋和身高没有必然联系。
{% endnoteblock %}

完全可以。即便更高的身高在杀球的时候比较容易拿到更高的点位，从而打出角度更为尖锐的杀球。不过相应的，大个子同学也会在转身、前后跑动等方面出现因身形过大带来的问题，在接杀等需要降低重心的准备中也并不占优。

小个子同学在速度和灵活性方面就会更胜一筹，虽然没有身高带来更为广阔的防守范围和进攻角度，也能在其他的战术中发挥意想不到的作用。

## 4 心态与锻炼方式

打羽毛球嘛，我们不能要求每个人都以比赛的认真态度去对待她。

有些人想要变得更强，获得更多的关注与胜利。

而有些人只是想和朋友有一个交流方式，一个流汗的契机来打打养生球休闲球而已。

所以我们首先要明确自己是为什么样的态度与目的，万不可迷失自己的方向。

在这一章节我将给出“休闲球”，“认真球”两种不同心态下的打球方式，提供一个锻炼与训练不同方面的参考。

### 休闲球与爱好

只是想用羽毛球作为一个常用的锻炼方式，毕竟它干净卫生还优雅，有一小块场地就可以轻轻松松达到全身运动的效果。

那么这类球友的目的是和对方打尽量多拍的回合，相比于让球在对面落地，更在意的是它不能在我们的这一边落地。

因此，一个较为正确的挥拍姿势与步伐是相当重要的。

正确的挥拍姿势可以让你有足够的力气将球击打回去，而良好的步伐可以让你更快地到达你想去的地方从而更加从容地击球，也能保护自己不要受伤。

### 变得更强

这类球友想要和更多更厉害的人交手，享受和更强的人对战之后体能耗尽的快感，享受比赛胜利之后场下的欢呼。
