## 1 羽毛球拍

最最激动人心的环节，我们来挑选手中斩杀敌人的剑。

首先我们先了解一下球拍的基础参数，然后根据这些参数原理我将给出性价比较高的装备推荐

### 基础参数

{% folding red :: 球拍重量 %}

球拍重量的计量单位为: U
常用的球拍重量由轻→重: 5U/4U/3U

球拍重量和球拍的“攻击性”算是正相关（并不绝对），越重的球拍对个人的力量要求会更高，相对的，打下去的球就更重。

而更轻的球拍会有更快的挥速，能保持击球的连贯。

建议女生和初学者选用5U/4U的重量，力气大后可以尝试3U的重量。

> 李宁采用的是W计重，数字大小与重量成正比，和U是相反的。W2/W3与4U/3U基本相同。

{% endfolding %}

{% folding yellow :: 手柄粗细 %}

手柄粗细的计量单位为: G
常用的手柄直径由粗→细为: G1/G2/G3/G4/G5

拍柄并非直觉上的圆柱体，而是一个{% emp 八边形 %}。这不光是出于摩擦力上的考虑，也更是为了发力和正反手握拍做出区别。也正是因为如此，我会不太推荐“龙骨手胶”。

拍柄粗细并非特别重要的参数，一般一种型号的拍子都只有固定的1~2个手柄粗细。

> 细手柄可以通过各种手段调整，比如缠防震膜、两层手胶等等来加厚。

{% endfolding %}

{% folding green :: 拍杆 %}

拍杆的参数一般我们只考虑两种：材质和软硬

首先谈谈{% u 材质 %}。目前市面上主流的材质为碳素纤维——材质轻、有韧性，不易产生永久性形变。
如果不想花费太多的钱在拍子上，也最起码购买一支标明了“碳纤维”的球拍，当然，它也不会太贵，甚至不会超过150rmb。

至于铝合金、碳铝合金材质的球拍，即我们常说的“超市拍”，它唯一的优点是比较便宜，40rmb甚至可以买两只。我{% span red, 强烈不建议你使用这种材质的球拍 %}。因为它们通常又重又不结实，会因为自重伤害到使用者的手腕，更不用说其断裂的风险更高。

关于{% u 软硬 %}，就是很多球友常说的“硬中杆”，“软中杆”。它目前还没有一个具体的参数来描述，所以大部分都是靠感觉和厂商遵守广告法的自觉。

球拍在击球的一瞬间拍杆会产生一定的形变，做一个不甚恰当的形容，硬中杆像棍子，软中杆像鞭子。

在区别上，硬中杆要求更大的力量，也带来了更精确的落点。
软中杆在牺牲少许落点精度下，会让你更轻松地将球打得更远。

多试试拍子，就知道自己喜欢哪种软硬的拍子了。

> 李宁的中杆通常比标注的药略软一些，尤尼克斯几乎都是极硬中杆。

{% endfolding %}

{% folding cyan :: 拍框 %}

拍框需要考虑的参数是拍框的横截面形状，分为两种：{% u 盒式框 %}和{% u 破风框 %}。

盒式框会带来更高的击球稳定性，通常用于进攻性更强的球拍。
破风框会带来更快的挥速，通常用于需要快速连贯或者双打的球拍。

以上也不绝对，只能从手感上来说，破风框挥起来要更为快一些，而盒式框在大力击球的时候可以提供一定的借力。

也有出现“双面异型框”等其他混合形制或者特殊的拍框，这些就依靠自己去探索吧~

> 大部分适合扣杀的暴力拍会用盒式拍框，大部分双打或者速度拍会采用破风拍框。

{% endfolding %}

{% folding blue :: 平衡点 %}

平衡点用来描述羽毛球拍是拍框端更重还是手柄端更重，它是影响挥动手感的最主要的因素。平衡点以拍柄底端为起点开始，球拍重心为终点。

球拍平衡点的范围一般在 280mm ~ 320mm 之间。

285以下属于拍头轻速度型，挥速快、连贯快、更稳定，一般称为防守型；
285-295属于平衡性，适合控球；
大于295的拍子属于头重型，挥拍提供借力、力道更大，一般称为进攻型。

{% endfolding %}

{% noteblock guide :: 需要考虑的基本参数 %}
球拍重量: 5U/4U/3U
拍框: 盒式拍框/破风框/双面异型框
平衡点: 进攻型 or 平衡型 or 防守型
{% endnoteblock %}

还有更简便地判断球拍属性的方法——直接看看评论区和球拍评测是怎么说的，毕竟同一型号的球拍，它的特性总是大差不差的。

### 一点小碎碎念 - 为何我建议初心者先拍后鞋

在球拍的选择上，我更建议大家多花一点点钱买一个差不多可以一直用的中高端球拍。一只相对优秀的球拍能给人更好的击球体验，从而激发打球的乐趣和学习的欲望。

然而实际上，羽毛球鞋的重要性要更甚于羽毛球拍，所以您可能会在各种教程上听到很多人建议大家用500+的预算来搞定一双球鞋而不是球拍。

诚然，对于训练学生或者进阶爱好者是这样的，但对于初学者而言，集中感受到打球的乐趣——球击中拍线的一瞬间，才是我认为更重要的事情。

何况，到了你不需要这些装备——不论是选择了其他运动，还是更新了更高端的装备——时，出一个二手球拍总是比出一双二手球鞋要更容易的。

当然你也可以把球鞋当日常鞋来穿，但羽毛球鞋相对全面的包裹感总是和舒适透气无缘，它的设计也不一定好过设计师专门为休闲场景设计而不必过于注重功能性的其他鞋们。

更何况羽毛球鞋的橡胶底是相当脆弱的，在室外场景踩水、风化等情况反应后会变得又硬又滑，甚至还会裂开。

如果本来自己就有其他运动的爱好——像是篮球鞋的鞋底科技、包裹性、抗扭与脚踝保护就和羽毛球基本同源——完全可以在“玩”的基础上使用这些鞋子，毕竟羽毛球的上限与下限都相当不可思议呢。

## 2 羽毛球鞋

{% noteblock quote %}
你打不到球，总是因为你离球太远。
{% endnoteblock %}

羽毛球鞋对于这项运动的作用是毋庸置疑的，在全场步伐的跑动当中，急停、跳跃、转身这些动作的频率和呼吸相比估计都不遑多让。因此，一双优秀的羽毛球鞋绝对是进阶球友{% emp 比对羽毛球拍还重要 %}的选择。

当然，这里的进阶指你已经开始练习正确的羽毛球步伐，并应用在实战当中。如果还是仅仅限于在球场上跑步接球的话，那这些知识其实都不必要啦。

### 四大参数

挑选羽毛球鞋在性能上需要看四大参数：抗扭、缓震、包裹、重量

{% folding red :: 抗扭性 %}
抗扭性体现在使用球鞋急停的时候会不会侧翻，以及前后脚掌进行旋转会不会提供一定的支撑力。比较好的球鞋会采用一种“碳板”科技，插在前脚掌和脚跟两块大橡胶之间。
{% endfolding %}

{% folding yellow :: 缓震 %}
缓震主要是鞋底的材料与厚度决定的，优秀的缓震可以降低跳跃后落地对脚掌的冲击，也能吸收在急停时强大的惯性。

一般来说，缓震更好的鞋也会更重、更稳定，包裹性更好
{% endfolding %}

{% folding green :: 包裹性 %}
包裹指鞋面对脚掌的挤压，良好的包裹应该对脚掌有一定的压力，也能起到很好的保护作用。

这层包裹有薄有厚，厚的能提供更优秀的保护，也能减轻磨脚的情况，而薄的就是偏向透气了。
{% endfolding %}

{% folding cyan :: 重量 %}
重量会影响整个球鞋的属性，也和上面所有的属性都有所关联。

轻的鞋会更容易启动一些，可以有更高的舒适度和更快的速度；重的鞋会更注重保护与稳定，让你能更有底气做更加激烈的动作。

这是选择球鞋最直观的一项数据。
{% endfolding %}

### 如何挑选

大部分厂家的球鞋都会有一个大致的分类，我们可以通过这些分类快速筛选自己需要的球鞋。

|分类|球鞋属性|价格|备注|
|:----:|:----:|:----:|:----|
|日常训练类|均衡、耐磨|<300|一般的训练鞋在200左右，属性会比较均衡，鞋底相较于其他也会更耐磨一些，是最推荐初学者购买的|
|稳定保护类|稳定、重、包裹性好|300~1500|适合力量更大、经常跳跃、爆发力强的球员|
|快速启动类|轻、快|300~1500|更适合双打、节奏更快的球员|
|全面均衡类|各项均衡|300~1500|全面的专业比赛鞋，各种场景都适用|

因为我自己使用的球鞋并不多，有很长一段时间都逮着尤尼克斯的65Z系列使劲薅，也就不推荐具体型号了。需要注意的有以下几点

1. 胜利的羽毛球鞋在业余爱好者中口碑最好，更适合大多数人，且物美价廉。
2. 不同品牌的鞋型可能有所区别，如果一个品牌的鞋磨脚的话，就不必纠结与某个型号。
3. 李宁的球鞋是设计感最强最潮的，但有时你可能会觉得它非常花里胡哨，不过它的球鞋设计完全作为日常鞋穿出去。
4. 尤尼克斯宣传的碳板是假的，使用的是一种平替的塑料板，不过因为性能差不太大，所以目前还能被消费者容忍。
5. 胜利的球鞋中的白色打底是三家里面最多的。
6. 阿迪达斯的球鞋会重一些，亚瑟士的球鞋会硬一些，还是更建议选择御三家的球鞋。
7. 李宁的“水晶底”在胶皮球场上性能非常好，但是相对不耐磨。

关于羽毛球，你还需要了解这些事情：

1. 羽毛球的质量和品控有关，有可能你在某个时间里买的某一种球出乎意料的好，也有可能出乎意料的差，这可能是因为当时的那一批鸭子，或者鹅的心情出现了小范围的波动。

## 4 羽毛球拍线

球拍线是和球接触最为密切的装备了{% del （如果你不打杆的话） %}，因此，球拍线的选择也是影响击球手感的一大因素。

{% noteblock quote %}
俗话说得好：三分拍，七分线，剩下九十分是自己的水平。
{% endnoteblock %}

在球拍线领域中，做得最好的仍然是YONEX，在任何一个拉拍线的地方总是yy的线是最多的。

### 关于磅数

磅数就是拍线的松紧度，越高的磅数，拍线就被绷得更紧，整体的球拍打感也会更硬、更震手，也需要更强的力量才能够掌控。

高磅数会减少球在拍线上接触的时间，因此会提高出球速度，其更少的形变也会带来更为精确的指向性，让控球精度提升。然而相对的，需要更强的力量和正确的发力方式才能掌握高磅数的球拍，如果你没有足够的力量，高磅数的球拍会震伤你的大臂肌肉（正确发力下），{% emp 甚至造成撕裂 %}。

{% psw 不正确发力呢？手腕挫伤、小臂拉伤、肩部扭伤等，都是可能出现的损伤。 %}

低磅数则有更强的弹性，可以用更小的力气打出更远的距离，因此初学者还是就建议选择比较低的磅数。

> 最开始选择磅数时最好不要超过22~24磅，之后再根据力量和水平上升。

### 选择拍线

球拍线也基本上只看型号了，因为拍线是消耗品，所以不必太过于纠结自己选择什么样的拍线，多打一打，尝试更多的线之后，自然就能确定自己到底适合什么样的。

对于初学者而言，相对粗一些的线，增加一些耐打性从而降低打到非甜区（球拍的非最佳受力区，即靠近拍框的地方，甚至是单线区）造成意外断线的风险，也能节省更多的资金。

耐打线的话，尤尼克斯的BG65和李宁的5号线（或者N69）都是不错的选择。

{% noteblock message :: 穿线师是否专业？ %}
穿线师这条线是否穿得良好，最简单的判断方式是看线上的印字是否平直没有扭曲，好的穿线是不能扭线的。
至于打2个或4个结，从来都不是判断标准。
{% endnoteblock %}

### 断线处理

在球包中多携带一把剪刀，一旦球拍断线，就要尽快从中间或断线的地方用{% emp 画十字 %}的方法把线剪断，防止不均匀的拉力破坏球拍结构。

剪拍线的方法非常好记，以断线处为中心，横竖相间，总体以画十字的方法完全剪断即可。如果实在无法判断如何剪线，可以在剪线的时候用手指稍微拨一拨拍线，挑里面拉力小的剪掉就好了。

{% noteblock message :: 剪线的几个要点 %}
1. 断线立刻剪断，不要放
2. 画十字，一横一竖，找拉力小的线剪
3. 完全剪断，不要留部分不剪
4. 不抽线
{% endnoteblock %}

在剪完所有的拍线后，不要自己把拍线抽出，交给穿线师处理是最好的。自己抽出拍线有可能造成护线管（在拍框上线从中经过的黑色小管）的丢失，这个黑色小管的主要作用是防止穿线时线被划伤，以及增大受力面积，防止拍孔塌陷。

其实最大的原因是这个护线管一套25r。

## 5 羽毛球包

羽毛球包大致有3中类型：双肩包、双肩长包以及单肩包。

在选择球包时，注意球包有没有鞋仓，可以把球鞋单独收纳的地方，否则就需要单独买一个鞋包来将球鞋和其他物品隔开。

这些球包都有专门放置球拍的地方，内置保护层，可以较好地保护存放在其中的球拍，防止磕碰造成不必要的损伤。一般而言单肩包的收纳量是最大的，这些球包的收纳量在2~6把球拍不等。

在球包中，一般需要放置如下的物品：

1. 多把羽毛球拍
2. 一双球鞋
3. 一桶羽毛球
4. 几件替换的衣服
5. 运动毛巾
6. 运动饮料或水杯
7. 需要用到的护具
8. 紧急处理的药品
9. 自己的其他小玩意儿，手机钱包什么的

这么看来，一个羽毛球包还是很有必要的。

## 6 护具

羽毛球这项运动中，需要保护的地方倒是挺多的，因此各种各样的护具御三家都有售卖，我做一个列表吧。

1. 【护腕】 用于保护手腕，不过也会影响挥拍角度
2. 【髌骨带】 固定髌骨，增加压力，保护膝盖
3. 【踝部绑带】 固定脚踝，提供支撑力
4. 【护臂】 给大臂肌肉加压，防止拉伤（不常用）
5. 【护腰】 保护腰的，很多打球的中老年人在用
6. 【护膝】 相比于髌骨带，保护的范围更大一些

## 7 医药

羽毛球运动中，最需要关注的伤病除了正常的运动损伤之外，就是各个关节和肌肉的拉伤、挫伤和扭伤了。

### 云南包药气雾剂

{% image https://site.lyrikp.art//article/course/基本羽毛球食用手册/YNBY.png :: alt=云南白药气雾剂 :: width=200px %}

{% u 云南白药气雾剂 %}是大名鼎鼎的国家保密方，活血散瘀、消肿止痛，可以有效缓解肌肉酸痛和辅助关节损伤修复。

需要注意的是，包装的云南白药气雾剂分为白瓶和红瓶，红瓶是保险液，仅有镇痛的功效，是紧急扭伤处理时喷涂的；白瓶是药液，具有消肿活血的功效，是之后恢复时持续喷涂的。

另外，也不建议长时间连续使用这些药物（每天3~5次，超过两个星期），因为其含有草乌等毒性成分，对自身的恢复力也可能产生影响。

{% noteblock message %}
尽管科学研究和成分表证明其并不存在依赖性成分，但因为喷口声音的爽快感、药物独特的气味以及药液在皮肤上微凉的感觉，基本上所有使用过该气雾剂的同学都表示它会产生成瘾性，喷了之后还想喷。
{% endnoteblock %}

### 扶他林软膏

{% image https://ss3.baidu.com/9fo3dSag_xI4khGko9WTAnF6hhy/zhidao/pic/item/cdbf6c81800a19d83663a69b38fa828ba71e46cf.jpg :: alt=扶他林软膏 :: width=200px %}

扶他林软膏的全称是{% u 扶他林双氯芬酸二乙胺乳胶剂 %}，同样也是针对肌肉酸痛和关节损伤的药物。

扶他林还有其他种类的药物，像是缓释片、胶囊等，在运动上常用的是软膏类的药物，和云南白药不同，扶他林软膏是需要揉搓药物在伤患处化开吸收的。

相比较而言，扶他林的价格会更贵一些，但它的效果是立竿见影的好，尤其是针对肌肉酸痛、拉伤的效果，在短短几分钟内就可以消除疼痛。虽然不是完全治愈，但其镇痛的效果在很多同学的反馈中是优于云南白药气雾剂红瓶的。
